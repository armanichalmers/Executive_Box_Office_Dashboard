# 📊 Executive Box Office Sales Dashboard

## Project Overview

This project was developed during the **Tivoli Data Analytics Career Accelerator Program**, a 12-week applied analytics program through eXcelerate Analyst Training.

Working as part of a three-person analytics team, I developed an interactive **Microsoft Power BI dashboard** using organizational Box Office data from the **Tivoli Theatre Foundation**. The dashboard was designed to provide executive leadership with a clear, interactive view of Month-to-Date (MTD) Box Office performance and key operational metrics.

The completed dashboard was presented to the organization's **Chief Operating Officer (COO)** to demonstrate how the solution could support performance monitoring and executive decision-making.


## 🔒 Data Privacy Notice

This project was originally developed using real organizational data. To protect organizational confidentiality, the publicly displayed version has been anonymized and modified. Event names, values, and other identifying information shown in the portfolio dashboard do not represent actual organizational performance.

## 🎯 Business Objective

The objective of the dashboard was to transform Box Office data into an executive-friendly reporting solution that allowed leadership to quickly evaluate performance and explore key business metrics.

The dashboard was designed to answer questions such as:

- How much revenue has been generated from ticket sales?
- How many tickets have been sold?
- What is the average ticket price?
- How many shows contributed to the reporting period?
- Which events generated the highest gross ticket sales?
- How does ticket performance vary across entertainment genres?
- How does Box Office performance change throughout the reporting period?


## 📈 Key Performance Indicators

The dashboard tracks four primary KPIs:

- **Gross Ticket Sales**
- **Total Tickets Sold**
- **Show Count**
- **Average Ticket Price**

Additional visualizations allow users to analyze:

- Top events by gross ticket sales
- Ticket sales by genre
- Genre-level revenue and ticket performance
- Box Office performance over time


## 🛠️ Tools & Technologies

- **Microsoft Power BI** – Dashboard development and data visualization
- **Microsoft SharePoint** – Source location for reporting data
- **Excel** – Source data and supporting reporting
- **GitHub** – Portfolio documentation


## 🔍 Dashboard Features

The interactive dashboard includes:

- Executive KPI cards
- Event Year slicer
- Month slicer
- Genre slicer
- Site slicer
- Genre-level performance table
- Top Events by Gross Ticket Sales visualization
- Total Tickets Sold by Genre visualization
- Box Office performance trend visualization

The slicers allow users to dynamically explore performance across different time periods, genres, and locations.


## 💡 Analytical Approach

The dashboard was designed with executive usability in mind. I focused on presenting high-level KPIs first, followed by more detailed visualizations that allow users to explore the factors contributing to overall Box Office performance.

The dashboard combines summary metrics with event-, genre-, and time-based analysis so users can move from an executive overview to more detailed performance insights within a single reporting solution.


## 🤝 Collaboration

This project was completed as part of a **three-person analytics team** during the Career Accelerator.

Team members collaborated on dashboard development, data validation, visual design, and the organization of business metrics to ensure the final solution communicated Box Office performance clearly and effectively.


## 🎤 Executive Presentation

The completed dashboard was presented to the **Tivoli Theatre Foundation's Chief Operating Officer (COO)**.

During the presentation, we communicated key operational KPIs and demonstrated how the interactive dashboard could be used to monitor Box Office performance and support executive decision-making.
